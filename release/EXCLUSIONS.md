# Excluded material

This fresh release intentionally excludes the original repository history and all
working-only material, including:

- agent instructions, prompts, handoff files, and coordination mailboxes;
- dissertation manuscripts, reports, study guides, supervisor presentations,
  weekly notes, handbooks, and writing briefs;
- internal reviews, planning packets, calibration diaries, and superseded prose;
- historical site-specific Slurm launchers and shell helpers;
- datasets, feature caches, checkpoints, generated outputs, and logs;
- raw Test-Dev photographs and the full upstream question/gold corpus;
- third-party source trees and virtual environments.

Only files named in `ALLOWLIST.txt` belong to the release. A missing useful file
must be reviewed and added explicitly; broad copy globs are not allowed.
